# State ex rel. King v. Marvin

## Majority (Per Curiam.)

Per Curiam.
The tender in this case was by cash, made ujion the same basis as the tenders in the preceding case and for a similar assessment for the same improvement. The facts are substantially the same in this as in the preceding case, and for the reasons given in the opinion delivered therein the writ in this case is refused.
